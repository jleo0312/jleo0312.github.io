PORTFOLIO UPDATE — 23 SEPTEMBER 2026

The website files were updated previously, but the repository still had the older editor configuration. Complete both steps below so the new controls appear.

1. UPDATE THE WEBSITE
Open https://github.com/jleo0312/jleo0312.github.io

Upload app.js, style.css and index.html from this extracted ZIP into the main repository folder, then commit the changes.

2. UPDATE THE EDITOR
Open EDITOR-CONFIG.txt from this ZIP in a text editor.
Press Ctrl+A, then Ctrl+C to copy all of it.
Open this GitHub editing page:
https://github.com/jleo0312/jleo0312.github.io/edit/main/.pages.yml
Click inside the code, press Ctrl+A, then Ctrl+V to replace the entire editor configuration, and commit the change.
Keep the filename exactly .pages.yml.
The .pages.yml file included in this ZIP contains the same configuration if you prefer to upload that file directly.

3. REOPEN YOUR EDITOR
Reopen the editor for jleo0312/jleo0312.github.io on branch main.
You should now see “Website settings & icon” alongside “Edit portfolio”.
After GitHub finishes publishing, refresh the website with Ctrl+F5.

  Your existing “About me: second paragraph” text is already used here.
  The main bio stays beside the photo. On desktop, the photo expands to fill the space above the caption and the bottoms of the two text areas align. On phones they stack.

  Turn it off to remove that project from both the gallery and homepage highlights. A direct link to its project page still works.

• Website icon: Website settings & icon → Website icon & browser tab → Website icon (browser tab).
  Upload a square PNG or SVG, then save. Open a fresh browser tab if the old tab still shows its cached icon.

  This includes “A little about me”, “Hobbies”, “Ideas. Made real.” and the other headings and labels.
